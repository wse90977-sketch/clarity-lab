    A QUICK GUIDE

    Less guessing. More doing.

    How do I add a task?

    Type a task in the field above and select Add task, or press Enter. Give it a clear action, such as “Read chapter 4.” Tasks must contain at least one non-space character and can be up to 120 characters long.

    How do I finish a task?

    Select the checkbox beside a task. A line through the text shows that it is complete. Select the checkbox again if you need to reopen it.

    What do the filters do?

    All shows your whole list. Active shows unfinished tasks, and Completed shows tasks you have checked off. Switching filters does not delete anything.

    Can I remove something?

    Select Delete beside the task you want to remove. The task will leave the list immediately. Check the task name before deleting it.

    Will my tasks stay here?

    The app tries to save tasks in this browser on this device. Clearing browser data can erase them. Private browsing may remove them when the window closes. If storage is unavailable, the app displays a notice and keeps tasks only while this page stays open.

    Where should I start?

    Add one useful task, complete it, and try the Completed filter. Then return to All to plan your next step. A short, specific list is easier to work through than one large, vague goal.
